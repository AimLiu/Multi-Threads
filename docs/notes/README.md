# 学习笔记索引

本目录按「一个模块一个文件」组织，与 `docs/learning-plan.md` 的 10 个模块一一对应。每学完一个任务，就把该任务的**概念梳理**（用自己的话重写，重点记录易错点）和**思考题结论**追加到对应模块文件。

## 使用约定

- 思考题务必先自己作答，再对照文档里的结论补充差异。
- 命名规则：`m<模块号>-<主题>.md`（如 `m2-race-jmm.md`），与学习计划里的引用保持一致。
- 更新文件后，顺手更新本页「文件清单」里的「已覆盖任务」和「最后更新」。
- 模块 0 是纯环境搭建，无概念，不建笔记。
